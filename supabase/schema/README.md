# Supabase Schema

This directory contains the authoritative database schema for the application.

## Files

- **`schema.sql`** - Complete database schema dump
  - Auto-generated by GitHub Actions workflow
  - Contains tables, types, functions, triggers, indexes, and RLS policies
  - **DO NOT EDIT MANUALLY** - will be overwritten on next sync

## Synchronization

The schema is automatically synchronized from Supabase:

- **Schedule**: Daily at 2 AM UTC
- **Trigger**: Manually via GitHub Actions
- **Workflow**: `.github/workflows/sync-supabase-schema.yml`

See [SCHEMA_SYNC.md](../SCHEMA_SYNC.md) for detailed documentation.

## Usage

### Viewing the Schema

```bash
# View the complete schema
cat supabase/schema/schema.sql

# Search for specific tables
grep "CREATE TABLE" supabase/schema/schema.sql

# View RLS policies
grep "CREATE POLICY" supabase/schema/schema.sql
```

### Applying the Schema

To recreate the database from this schema (for new environments):

```bash
# Using Supabase CLI
supabase db reset

# Or manually via psql
psql $DATABASE_URL < supabase/schema/schema.sql
```

### Schema History

```bash
# View schema change history
git log --follow supabase/schema/schema.sql

# See what changed in the last sync
git show HEAD:supabase/schema/schema.sql
```

## Making Schema Changes

1. Make changes in Supabase Dashboard or SQL Editor
2. (Optional) Document changes in `supabase/migrations/`
3. Wait for automatic sync or manually trigger workflow
4. Review and merge the automated commit

See [SCHEMA_SYNC.md](../SCHEMA_SYNC.md) for the complete workflow.
