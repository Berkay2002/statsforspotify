This repo commonly includes route-level loading UIs for dashboard pages.

## Building blocks

- `components/ui/loading-skeletons.tsx`
  - `PageHeaderLoading`
  - `TimeRangeTabsLoading`
- `components/ui/skeleton.tsx`
- Example loading page: `app/(protected)/dashboard/artists/loading.tsx`

## Guidance

- Default: add `loading.tsx` for new dashboard routes.
- Match the page layout density (grid vs list).
